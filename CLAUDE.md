# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personalized graduation site, now a thank-you letter after the ceremony (25/11/2026). It was an invitation with RSVP before; that version is in git history (before the thank-you commit). The page thanks everyone who came, sent gifts or only sent wishes, so no copy may claim the reader was there. Each guest has a private `/t/<slug>` link that greets them by name and form of address; the public link (`/`) thanks "mọi người". Guest data and private messages live in a Google Sheet. All site copy, code comments and error messages to users are in Vietnamese.

`../CLAUDE.md` describes a different project (the `UI/` React portal). It does not apply here.

## Commands

```bash
npm run dev                  # http://localhost:3333, no config needed (PORT=4000 to change)
npm test                     # node --test test/*.test.js
node --test test/validate.test.js                          # one file
node --test --test-name-pattern="<name>" test/*.test.js    # one test
npm run guest -- "Họ Tên" chị            # generate slug + row for the Khach tab
npm run guest -- --file danh-sach.csv    # bulk: ho_ten,xung_ho,nhom,kenh_gui
```

Requires Node >= 20. There is no build, bundler, linter, type-checker, or npm dependency, and the code is plain ES modules. Keep the server dependency-free: Google auth is a hand-rolled RS256 JWT via `node:crypto`, and Sheets is called over REST with `fetch`. The browser libraries are GSAP 3.15.0 (`public/vendor/gsap/`) and three.js r128 (`public/vendor/three/three.min.js`), committed as minified builds and loaded as classic scripts, so they are globals (the CSP rules out a CDN). `canAnimate()` in `util.js` lists the required GSAP ones; without them, or with reduced motion, the page runs with no animation. three.js is optional on top of that: every WebGL module returns early without `THREE` or when `new WebGLRenderer()` throws, and its init is wrapped in try/catch, because decoration must never stop `boot()`.

## Architecture

**Frontend (`public/`)** is served as static files. `/t/:slug` rewrites to `index.html`, and the client reads the slug from the URL (or `#<slug>` for testing). `main.js` renders static content first, then fetches the guest. A known slug greets by `pronoun()`; no slug, an unknown slug or a network error falls back to `GENERIC_GUEST` ("Mọi người"). Sections: terminal hero, album (`gallery.js`: the guest’s own photo, a CSS-3D photo ring from `PHOTOS`, the Google Drive album from `ALBUM.driveUrl`), message form (`wish.js`, on every link), campus map, footer. The `/api/rsvp`, `/api/calendar` and `/api/map` endpoints and `calendar.js`/`arrival.js` are still there for the server and tests, but the page no longer calls them.

**Splash and scrolling:** `html.splash-on` is set in the HTML and locks scrolling until `splash.js` clears it. `boot()` starts it right after the static render and never waits for fonts or images, so guests see motion immediately. The splash is a three.js scene: a particle galaxy that morphs into the guest's name once `setGuest()` arrives (text is sampled from a canvas in Chakra Petch, then a crisp HTML `#spName` fades in over it), plus a 3D cap. `splash.ready` resolves when the galaxy has faded in, not when the name is formed. After the guest data and `splash.ready`, `boot()` starts ScrollSmoother and `scroll-effects.js`, then waits on `splash.tapped` and calls `splash.open()`, which tosses the cap, bursts the particles and fades the background; `opening` resolves mid-way and `main.js` runs `playHeroIntro()` (`hero.js`) on it. The tap is what lets the browser start the music: the hint appears once the name is formed, and the splash opens by itself `AUTO_OPEN` seconds later. Guests who turned the music off have no gate, so `open()` waits for the name plus `HOLD_MS` before opening; an early tap jumps the name to its final state. The 8s CSS failsafe on `.splash` only covers JS failing to load. Once `splash.js` runs it switches to a GSAP timer (`FAILSAFE`), because a background tab pauses GSAP but not CSS. Without WebGL (`.splash.no-gl`) the same flow runs with HTML text only. The renderer is disposed after opening. Reveals wait on `splash.opening`, so above-the-fold ones are seen. With ScrollSmoother active, `scrollIntoView` does nothing, so use `ScrollSmoother.get().scrollTo` (see `decor.js`, `gallery.js`).

**Other effect modules:** `gallery.js` (the photo ring spins on `gsap.ticker` only while in view, writes only transform/opacity, and stands up from a tilt on scroll; drag uses `touch-action: pan-y` so vertical scrolling still works, and `pointercancel` must not open the lightbox; the lightbox pauses ScrollSmoother and restores focus with `preventScroll`, or the page jumps back to the album), `fx.js` (confetti when the card is stamped, hearts and a paper plane after a message; it no-ops in tests and with reduced motion, and callers wrap it in try/catch so a decoration error never turns into "chưa gửi được"), `map3d.js` (3D campus map driven by `ROUTES[].campus`; `map.js` keeps the 2D SVG as fallback and toggles `.map.has-3d`), `bg-graph.js` (commit-graph background, renders only when scroll or pointer changes and never while the splash covers the page). If a section ever needs to hold still while scrolling, do not use a ScrollTrigger `pin` on touch-only devices: the page scrolls natively there and a JS pin lags one frame and shakes on iOS; the old schedule used CSS `position: sticky` sized in `svh` (see git history). `ScrollTrigger.config({ ignoreMobileResize: true })` stops a full refresh every time the mobile address bar shows or hides. Per-frame scroll work must stay on `transform` and touch the DOM only when a value changes (see the photo ring, the `.gbar` fill), and must not read layout: `decor.js` measures section positions once and again on resize and on ScrollTrigger `refresh`. Panel reveals use opacity and transform only (no `clip-path`, which repaints the whole panel each frame). The crisp guest name on the splash is painted onto a `<canvas>` inside `#spName` (`paintName()`/`fitName()` in `splash.js`), with the name only in `aria-label`. Do not go back to HTML text with `background-clip: text`: iOS Safari did not repaint the clipped gradient after the font size grew on a GPU layer, so guests saw only the first word ("Chị" of "Chị Thự"). On phones `bg-graph.js` is off, and the WebGL modules cap pixel ratio; `map3d.js` draws at ~30 fps when idle. Reveal tweens use `clearProps: "all"` by default; override it for elements whose inline style carries layout (the ring cards keep their 3D `transform` inline, so they are never reveal targets). A CSS `transition` on a tweened property makes the tween lag; `#mePhoto` has one for hover, so its reveal sets `transition: none` first. ScrollSmoother needs `#smooth-wrapper` > `#smooth-content`; `position: fixed` elements must stay outside them, and page padding lives on `#smooth-content`. Scroll reveals use `opacity`, not `autoAlpha`, so unrevealed content stays focusable and readable by screen readers. On touch, ScrollSmoother does nothing but `scroll-effects.js` still runs.

**Content** all lives in `public/src/config.js` (event details, thank-you copy, `PHOTOS`, `ALBUM`, routes). Album photos go in `public/media/album/`; an empty `PHOTOS[].src` draws a labelled placeholder. `CẦN ĐIỀN` marks values still missing. `ROUTES[].focus` and `path` reference element ids and coordinates in the SVG map in `index.html`, so the two must change together. `ROUTES[].campus` (`lot`, `pts`, `stops`, optional `yaw`) feeds the 3D map, in the campus coordinates of `map3d.js`; `stops` has one index per hop, and every route ends at the same meeting point (both checked in `config.test.js`).

**API (`api/*.js`)** is Vercel serverless functions with `(req, res)` handlers. `_lib/` is not routed. Contract: `GET /api/guest?slug=`, `POST /api/rsvp`, `POST /api/wish` (private message to Hưng from any link; optional signature `name`; honeypot field `website`; optional `slug`, stored as `source` only if that slug is a real guest, private or shared; in-memory limit of 8 per IP+User-Agent per 10 minutes per instance, not per IP alone because a whole office shares one IP; the server records device label and IP, which the form discloses — keep that notice if you change what is stored), and `GET /api/map` (the embed URL for the Google Map iframe); the JSON content-type requirement on POST doubles as the CSRF check. A guest row with column I `link_chung` set (`x`, `có`, `chung`, `true`; see `isSharedFlag`) is a shared link for a whole group (for example the company group): `GET /api/guest` returns `shared: true`, `POST /api/rsvp` answers 400 `shared_link`, the message form asks each person to sign, and the guest photo uses the group copy (`COPY.group*`) and the wide `.me.wide` frame, because group photos are landscape with many faces. A row with column `anh_rieng` (a bare file name, `photoPath()` in `validate.js`) gets `photo: "/media/khach/<file>"`; the client accepts only that prefix. A landscape image switches any guest to the wide frame. A missing file shows a placeholder on localhost and hides the block in production.

**Storage** is selected in `api/_lib/store.js`, and both backends implement `getGuest`, `getRsvp`, `upsertRsvp`, `addWish`, `markOpened`:
- All three env vars set (`SHEET_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`): `sheets.js`.
- Env vars missing and not on Vercel: `local.js`, which reads `data/guests.local.json` or falls back to `guests.sample.json`, and writes `data/dev-store.json`.
- Env vars missing on Vercel: throws `not_configured` (503). It never silently falls back.

Tests inject a fake store with `__setStoreForTests` and a fake response with `fakeRes` from `test/helpers.js`. Sheets tests pass `fetchImpl` and `now` to `createSheetsStore`.

## Things that bite

- **Letter voice:** use `EVENT.graduateShort` ("Hưng") for self-reference, never "mình" or "tôi". Use `COPY.greeting` ("Gửi lời cảm ơn đến") for all recipients. Do not write that the reader came to the ceremony: many only sent wishes. Hero and splash show the same capitalized `pronoun()` result; body copy uses `{pron}` for the form of address plus short name. Keep action labels neutral.
- **Guest forms of address** are normalized by `public/src/address.js`, shared by the frontend, API and guest generator. `GUEST_CALLS` is a suggestion list, not an allowlist: custom text and blank values are preserved. `pronoun()` joins the form of address and short name, avoids duplicate titles, and uses "cả nhóm" / "anh em" alone. A blank form of address uses the short name (or full name); `fetchGuest()` falls back to the full name if the short name is missing. For a joint invitation, enter "cô Mai và bác Vinh" in the short name and leave the form of address blank. Only the public link uses "mọi người" (`COPY.genericCall`) with heading "Mọi người". Escape personalized text before inserting HTML.
- **Slug validation** is shared in `public/src/slug.js`: 3–64 ASCII letters (upper or lower case), digits or hyphens. Preserve case for URL parsing, Sheet lookup and RSVP writes; `cM-bV` and `cm-bv` are different identifiers.
- **Other client/server duplicates:** status labels (`sheets.js`, `rsvp.js`), and the 300-character message limit (`validate.js`, `rsvp.js`, `wish.js`, `index.html`).
- **Sheet column order is the schema.** Columns are read by index (`Khach!A:I`, I = `link_chung`; the one exception is `anh_rieng`, found by its header in row 1 (`Khach!A1:Z` is read with the header), absent header means no photos; `XacNhan!A:F`; `LoiChuc!A:F` is append-only: time, message, signature, device, IP, source slug). Status is stored as the Vietnamese label and read back as either label or code. Column F (`gio_den`) is the guest's chosen arrival window, defined once in `public/src/arrival.js` from `EVENT.guestWindows`; stored as its label, read back by code or by the "Đợt 1/Đợt 2/Cả hai" prefix so changing the times does not break old rows. The API requires it for `yes` and clears it for `no`.
- **Sheet writes must stay `valueInputOption=RAW`**, so guest messages starting with `=` are not run as formulas.
- **The `#confetti` canvas** is `display:none` except while `fx.js` has particles (`.on`). A canvas is a replaced element, so `inset:0` does not stretch it: without explicit `width`/`height: 100%` it sits at 300×150 in the top-left corner, and on iOS that idle fixed canvas flickered as a dark block over the hero while scrolling.
- **Guest names are untrusted.** Render them with `textContent`, DOM nodes, or `esc()` before `innerHTML`.
- **The dev server** applies the `vercel.json` headers, so CSP violations show locally. The CSP is strict (`script-src 'self'`, `connect-src 'self'`): no inline scripts or third-party requests. It also caches API modules, so restart it after changing `api/`.
- **Sheets guest cache:** 60s TTL per function instance, with a forced re-read on an unknown slug if the cache is older than 10s.

`design/thiep.html` is the approved design, kept for reference. It is not served.
